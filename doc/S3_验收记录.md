# S3 验收记录：RX RM 二分查找与状态 RAM

日期：2026-11-03  
范围：`afdx_rm_rx`、`afdx_rx_path`、`afdx_frame_rx` 握手、64 VL 压测

## 1. 实现内容

- 接收 VLID 配置表改为同步 RAM，要求运行时配置按索引升序写 VLID。
- 冗余状态改为独立同步读/单写口 RAM，记录：
  - `last_sn[7:0]`
  - `have`
  - `ic_window[15:0]`
  - `fault`
- 每帧执行 VLID 二分查找、候选配置读、状态 RAM 读、SN 判定和状态读改写。
- 新建 `afdx_rm_state_ram` 标准 RAM 子模块，避免 eLinx 将 64 项状态表展开为 LUT 选择器。
- 解析器新增 `rm_ready` 握手，`R_METW` 保持到查找与判定完成，避免固定 1 拍假设。
- 中间档顶层切换为 32 TX / 64 RX VL；4096 VL 与宽端口改造留给 S4。

## 2. 回归与容量压测

- 多驱动检查 PASS。
- 原 8 VL 接收用例全部 PASS：
  - 接受 10、重复 3、失序 4、未知 1；
  - 完整性错误 5、VL 故障 `00000010`、校验错误 7。
- 新增 64 VL RM 压测：
  - 131 次接受、128 次重复/过期丢弃；
  - 67 次接受型失序；
  - 131 次完整性错误；
  - 未知 VL 0；
  - 仅目标 VL 故障位置位；
  - `RESULT: PASS`。
- 顶层自环 24/24；双网冗余 47 收 / 24 交付，0 错误。

## 3. 综合与实现

条件：`AFDX_top`，32 TX / 64 RX VL，`EN_MGMT=1`，50 MHz SDC。

| 项目 | 结果 |
|---|---:|
| Synthesis | Successful，0 error |
| LUT | **13,267 / 136,160（10%）** |
| FF | **3,523 / 136,160（3%）** |
| Memory | **56,384 bit / 19 块** |
| WNS | **+0.870 ns** |
| 约束频率等效 Fmax | **约 52.28 MHz** |
| 布线错误 | **0** |

`cfg_ram` 与 `afdx_rm_state_ram.mem` 均已推断为 M4K。第一次实现因状态表展开出
−0.128 ns 违例；改为标准 RAM 子模块后恢复正 WNS。
