## 1. 容量测试

### 1.1 TX：128 VL 混合 BAG

`tb_afdx_tx_full.v` 配置 128 条发送 VL：

- BAG 按索引混合 1 / 2 / 4 ms；
- 功能数据长度混合 0 / 16 / 32 / 64 字节；
- 每条 VL 至少发送 3 帧；
- Python `check_frames.py` 模型检查字段、IP/UDP 校验和、FCS、SN、填充和 BAG。

结果：

- 共 724 帧；
- 单 VL 最少 3 帧；
- 所有 VL 起始间隔均不小于配置 BAG；
- 无 VL 饿死；
- `RESULT: PASS (128 VL)`。

本测试使用 1/2/4 ms BAG 并验证每条 VL 至少 3 帧。方案中的“10 万帧”
属于更长时间统计型压测；本次提交以全字段独立校验和全 VL 无饿死为主验收。

### 1.2 RX：4096 VLID 轮询

`tb_afdx_rm_full.v` 配置 4096 条升序 VLID：

- 每条 VL 首帧 + 重复帧全表轮询；
- 目标 VL 注入 3 次前向失序以触发故障；
- 检查 accept / dup / OOS / IC / fault 计数和状态索引读口。

结果：

- accept = 4099；
- dup = 4096；
- OOS = 3；
- IC errors = 3；
- unknown = 0；
- 仅目标 VL fault 置位；
- `RESULT: PASS`。

### 1.3 系统级

`AFDX_top`，128 TX / 4096 RX：

- 单路自环：tx 24 / rx 24 / deliver 24，0 error；
- 双冗余：tx 24 / rx 48 / deliver 24，重复副本 24，0 error；
- 全部 SNMP / RTC / 615A / 性能回归 PASS。

## 2. 最终综合与实现

条件：eLinx / EQ6HL130，`AFDX_top`，128 TX / 4096 RX，
`EN_MGMT=1`，50 MHz SDC。

| 项目 | 结果 |
|---|---:|
| Synthesis | Successful，0 error |
| LUT | **14,059 / 136,160（10%）** |
| FF | **3,876 / 136,160（3%）** |
| Memory | **174,144 bit / 46 块（4%）** |
| DSP | 0 |
| WNS | **+1.191 ns** |
| 约束频率等效 Fmax | **约 53.18 MHz** |
| 布线错误 | **0** |

关键 RAM：

- RX RM state RAM：`4096 × 26 bit = 106,496 bit`；
- RX VLID cfg RAM：完整记录 4096 × 17 bit；综合的有效字段报告为 12,288 bit；
- TX next_start bank：`32 × 32 bit = 1,024 bit`；
- TX VL 配置表仍为 4-bank RAM；模板顶层内部只配置 VL0 时综合器会静态化简未使用项。
