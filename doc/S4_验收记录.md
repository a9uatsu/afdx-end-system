# S4 验收记录：状态读接口与 128/4096 参数

日期：2026-11-03  
范围：RX 状态读口、管理故障快照、顶层 128 TX / 4096 RX 参数

## 1. 实现内容

- 删除 `afdx_rm_rx.fault_vec[N_VL-1:0]` 宽端口。
- 新增强类型按索引状态读口：
  - `status_req`
  - `status_idx[VW-1:0]`
  - `status_data[7:0]`，其中 `[0]=fault`、`[1]=en`
  - `status_ready`
- 状态读和帧元数据查询共享 RM 状态 RAM；增加挂起元数据锁存，避免轮询期间丢帧判定。
- `status_ready` 后维持 `STATUS_HOLD`，请求撤销前不重复接受同一索引。
- 管理通道轮询前 8 个接收 VL，维护 SNMP `vlFault` 兼容快照；未配置/未知状态安全归零。
- `AFDX_top` 切换到：
  - N_TX_VL = 128，TVW = 7
  - N_RX_VL = 4096，RVW = 12
- 赛题模板顶层端口保持不变。

## 2. 回归结果

- 多驱动检查 PASS。
- 原 AFDX、SNMP、RTC、615A、性能用例全部 PASS。
- 新增 32 VL TX 容量测试 PASS。
- 新增 64 VL RM 测试 PASS。
- 128/4096 参数顶层自环：
  - 单路 24/24 交付；
  - 双冗余 24 交付、24 重复，零错误。

## 3. 全容量综合与实现

条件：eLinx / EQ6HL130，`AFDX_top`，128 TX / 4096 RX，`EN_MGMT=1`，50 MHz SDC。

| 项目 | 结果 |
|---|---:|
| Synthesis | Successful，0 error |
| LUT | **14,059 / 136,160（10%）** |
| FF | **3,876 / 136,160（3%）** |
| Memory | **174,144 bit / 46 块（4%）** |
| DSP | 0 |
| WNS | **+1.191 ns** |
| 约束频率等效 Fmax | **约 53.18 MHz** |
| 布线错误 | **0** |

RAM 明细：

- RM 状态：4096 × 26 bit = **106,496 bit**
- RM VLID：4096 × 17 bit = **69,632 bit**（综合优化后按 3 bit 有效字段报告 12,288 bit）
- TX `next_start` bank：32 × 32 bit = **1,024 bit**
- 其余为管理通道、接收帧缓存和 TX 表/RX 配置等。
