# S1 验收记录：帧缓存双 bank 同步读

日期：2026-11-02  
范围：`afdx_frame_rx` 帧缓存、解析读路径、接收回归  
回退基线：`doc/refactor_baseline/afdx_frame_rx_S0.v`

## 实现内容

- 原 `2048 x 8` 组合读缓存拆分为两块 `1024 x 8` 简单双口 RAM。
- 写口按 `wr_ptr[10]` 选择 bank；读口同时寄存两个 bank 的输出及 bank 选择位，再合成 `mem_rdata`。
- 固定以太网/IP/UDP/AFDX 首部字段在捕获时锁存为 45 字节首部视图，避免解析器对整块缓存做大选择器。
- CRC、填充检查、UDP 载荷校验和及载荷交付改为同步读；扫描期间提前 1 拍给出下一地址。
- 保留原 `afdx_frame_rx` 端口和与 `afdx_rx_path` 的握手时序，不涉及 S2/S3 的 VL 表改造。

## 综合资源

为避免 `AFDX_top` 中未接出的接收观测端口被优化掉，S0/S1 使用相同的 `afdx_rx_path` 顶层包装做同口径综合。

| 版本 | Logic elements | Memory bits | 说明 |
|---|---:|---:|---|
| S0 | 103,731 | 0 | 2048x8 仍是组合/LUT 逻辑 |
| S1 | 2,662 | 16,384 | 推断为 2 个 1024x8 Simple Dual Port RAM |
| 变化 | **-101,069（-97.4%）** | +16,384 | 达到 S1 的 LUT 下降目标 |

综合工具：Quartus II / eLinx 13.0.1。S1 综合成功，0 error。当前 Stratix 映射下 16,384 bit 对应 4 个 M4K RAM；报告保存于 `doc/refactor_baseline/S1_rx_synth.map.summary` 和 `doc/refactor_baseline/S1_rx_synth.map.rpt`。

Quartus 13 对两个推定 RAM 给出 `dual-clock RAM` 的读改写行为提示。状态机保证捕获与解析互斥，不存在同拍读写；该提示不影响当前仿真与综合。后续实现阶段可在 Fit/时序复核时再次确认真实器件的 RAM 映射。
