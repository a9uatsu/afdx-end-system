# S2 验收记录：发送 VL RAM 表与后台扫描器

日期：2026-11-03  
范围：`afdx_vl_table`、`afdx_scheduler`、`afdx_tx_path`、32 VL 容量压测

## 1. 实现内容

- `afdx_vl_table` 改为 4 bank 交错存储，参数支持到 128 VL。
  - 每个 bank 保存 `252 bit × 32` 条记录；
  - 配置写口按 VL 低 2 位选 bank；
  - 扫描口每拍同时返回 4 个 bank 的使能；
  - 授权后单路同步读出完整记录。
- `afdx_scheduler`：
  - 增加 4 bank `next_start` RAM；
  - 每拍扫描 4 个 VL，128 VL 一轮 32 拍；
  - 就绪 VL 进入 16 深 FIFO，轮询授权；
  - 帧真正开始时写回 `next_start = now + BAG`。
- `afdx_tx_path`：
  - 授权后经同步记录读口锁存完整 VL 参数；
  - 再进行 SN 读取和帧组装，避免组合读整张 VL 表。
- 顶层中间档切换为 32 TX VL / `TVW=5`；最终 128 档在 S4 统一切换。

修复项：VL 表 `scan_en` 不能比同步 RAM 输出再晚一拍，否则扫描索引和
bank 使能错位。最终改为直接取当前 RAM 输出，系统回归恢复正常。

## 2. 回归与容量压测

- 多驱动检查 PASS。
- 原 15 项回归全部 PASS。
- 新增 S2 容量用例：
  - 32 条 VL；
  - BAG 混合 1 / 2 / 4 ms；
  - 帧长混合 64 / 80 / 96 / 113 字节；
  - 共发送 183 帧，每条 VL 最少 3 帧；
  - 所有 VL 最小起始间隔均不小于配置 BAG；
  - 字段、校验和、FCS、SN 检查 0 错误。
- 系统顶层：单路自环 24/24；双网冗余 47 收 / 24 交付，0 错误。

## 3. 综合与实现

条件：`AFDX_top`，32 TX VL / 8 RX VL，`EN_MGMT=1`，50 MHz SDC。

| 项目 | 结果 |
|---|---:|
| Synthesis | Successful，0 error |
| LUT | **13,079 / 136,160（10%）** |
| FF | **3,404 / 136,160（3%）** |
| Memory | **54,592 bit / 17 块** |
| WNS | **+0.805 ns** |
| 约束频率等效 Fmax | **约 52.09 MHz** |
| 布线错误 | **0** |

`afdx_scheduler.next_start` 的 `8 × 32 bit` bank 已明确推断为 M4K。
当前 `AFDX_top` 内部配置序列只写 VL0，综合器会将未使用的 VL 表条目静态化简；
完整的 32/128 条动态配置表 RAM 资源在 S5 专用综合顶层中复核。
